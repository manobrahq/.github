# Manobra

**The platform connecting people, professionals, and companies in construction.**

Manobra is a construction marketplace built to make it easier to **find work, find professionals, and get projects done**.

Whether you're a worker looking for opportunities, a company looking for skilled professionals, or a client looking for someone to get the job done — Manobra brings everyone together in one place.

---

## 🚧 What is Manobra?

The construction industry still relies heavily on word of mouth, scattered WhatsApp groups, Facebook posts, and outdated directories.

**Manobra is built to change that.**

Our platform makes it possible to:

- 👷 **Find work** — Discover construction jobs and opportunities.
- 🏗️ **Find professionals** — Connect with skilled workers and specialists.
- 📋 **Post projects** — Publish jobs and reach relevant professionals.
- 💬 **Communicate** — Chat directly with other users.
- 📍 **Find opportunities nearby** — Location-based discovery for projects and professionals.
- ⚡ **Promote your listing** — Increase visibility with Manobra Credits.
- 🛡️ **Build trust** — Profiles, verification, and reputation help users make better decisions.

## 🌐 Ecosystem

Manobra is built as a multi-platform ecosystem.

| Platform | Technology |
|---|---|
| 📱 Mobile App | Expo / React Native |
| 🌐 Web | Next.js |
| ⚙️ Backend | NestJS |
| 🗄️ Database | PostgreSQL |
| 🔌 API | GraphQL |
| ☁️ Infrastructure | Cloud & managed services |
| 🔐 Authentication | Apple / Google / Email |

Our goal is to provide a consistent experience across every platform while keeping the underlying architecture scalable and maintainable.

## 🎯 Our Mission

Construction is one of the world's biggest industries, yet finding the right person for a job can still be surprisingly difficult.

We're building Manobra to make that process:
